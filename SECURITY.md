# Security and Privacy

This repository is a sanitized portfolio refactor.

Never commit:

- `.env`
- Telegram bot tokens
- API keys
- access codes or secret files
- session/persistence files
- production SQLite databases
- real vehicle lists or plate numbers
- personnel information
- uploaded images
- generated operational reports
- private report templates

The original archive contained live credentials. Those credentials should be considered exposed outside their intended environment and should be rotated/revoked before reuse.
